## Singly Linked List Operations
 
Project

Implementation of singly linked list operations using dynamic memory allocation.

## Operations

- Insert a node
- Delete a node
- Search for a node
- Display all nodes

## Working

The program initializes the head pointer to NULL and displays a menu of operations. The user selects an operation, and the program performs insertion, deletion, searching, or displaying of nodes. The menu repeats until the user chooses to exit.

## Data Structure

Singly Linked List

## Programming Language

C++
